三个相互隔离的 Agent

不是三个标签页，是三条独立的运行时

DeepSeek Harness

内置官方 dsh CLI，一键拉起其本地 Web UI。官方 Web UI 需要一次性 token，由后端解析并脱敏为 token=*** 后再打开系统浏览器，不落日志。

Codex

使用系统 codex CLI，按需拉起、独立 CODEX_HOME；启动前先探测可用性，不做无意义的失败尝试。

DeepHarness（自研）

多步规划 → 工具执行 → 反思重试 → SQLite 长期记忆。核心循环由本项目的 Rust Worker 独立进程承载，支持插件扩展。

核心特性

为高效使用 DeepSeek 而生的桌面体验

流式对话

Markdown / 代码高亮 / 表格 / 引用块渲染，实时流式输出。

多模型切换

DeepSeek V4 Flash / Pro 全系，兼容任意 OpenAI 接口服务。

官方模型实时同步

自动拉取 DeepSeek 官方最新模型，无需升级客户端。

Agent 工具调用

读文本文件、写文本文件、列目录、建目录、删路径 —— 每个调用都必须先过该 Agent 的权限白名单。

便携模式

数据跟随应用目录，U 盘即插即用，无需安装。

系统托盘

关窗最小化到托盘，后台常驻，回合完成弹通知。

环境自检

启动即检测随包 Node、dsh 与系统 codex 的可用性，缺什么就在界面上说清楚，不静默失败。

本地隐私

对话、配置与记忆全部落在本机各自的目录里，零遥测，无账号，数据只属于你。

逐 Agent 权限白名单

每个 Agent 一份独立的 permissions.json；工作区隐式可读写，外部路径必须显式授权；按规范化前缀匹配，C:\dir 不会放行 C:\dir-evil。

插件系统

自研 .dph-plugin 格式，三重隔离：每次调用独立 node 子进程、文件系统限定在插件目录内、ctx 文件操作回流宿主过同一道白名单。内置工具优先，插件不可覆盖。

长期记忆

自研 Agent 把任务事件与结论沉淀到本机 SQLite 记忆库，下次任务可检索复用 —— 每个 Agent 各自独立，互不串味。

规划与反思重试

目标先拆成可执行步骤，逐步执行后由反思器逐步复检，失败即带错误反馈重试或修订该步，而不是整任务推倒重来。

安装与使用

三步开始，无需技术门槛

快速开始

  1. 前往 Releases 下载最新 DeepHarness_*.exe。
  2. 双击安装（默认装到用户目录，无需管理员权限）。
  3. 首次启动填入 DeepSeek API Key，选择工作目录即可开始。

从源码构建

npm install
npm run tauri dev   # 开发模式
npm run tauri build  # 打包安装程序

需要 Node.js ≥ 20（CI 用 22）、Rust stable-msvc 与 Visual Studio Build Tools。
打包前先跑一遍 bash scripts/setup-resources.sh 生成随包资源（Node 便携版 + dsh）—— resources/ 在 .gitignore 里，缺了它 cargo build 会在校验资源 glob 时失败。

常见问题

动手前最常被问到的几件事

怎么获取 DeepSeek API Key？
到 platform.deepseek.com 注册账号 → 控制台 → API Keys → 创建新 Key 并复制（以 sk- 开头）。Key 只保存在本机，不会上传。
这个项目是 DeepSeek 官方的吗？
不是。本项目是独立开发的第三方桌面工作台，与 DeepSeek 公司无官方隶属关系，也未使用其商标或图形标识作为本项目标志。对 dsh 与 Codex 都是以各自官方 CLI 的形式调用，代码按 MIT 协议开源。
插件怎么写、怎么装？
把 manifest.json 与 index.js 打成 zip、扩展名取 .dph-plugin，在应用里的插件面板导入即可。入口导出形如 module.exports = { tools: { async 工具名(args, ctx) { … } } }。插件运行在三重隔离下：每次调用起一个独立 node 子进程（超时即杀）、文件系统被限定在插件目录内、ctx.readFile / writeFile / listDir 会回到宿主过与内置工具同一道权限白名单。插件工具与内置同名时内置优先，且插件作用域按 Agent 隔离。
为什么安装包有 55 MB？
为了「装完即可用」：包里内置了便携版 Node 与官方 dsh，用户不需要自己装 Node、也不需要联网拉依赖。这部分占了绝大部分体积，换来的是零配置启动。若只想体验界面，可用 README 里的「从源码构建」自行打包瘦身版本。
支持 macOS / Linux 吗？
代码层面基于 Tauri 2，跨平台无障碍。但当前发布仅提供 Windows 安装包；macOS / Linux 用户可按「从源码构建」自行打包，命令相同。
会持续集成新模型吗？
会的。内置的「官方模型实时同步」会按需调用 GET /v1/models，DeepSeek 上线新模型后，设置里点「刷新官方模型」或在启动时自动拉取即可出现在切换菜单，无需升级客户端。
便携模式怎么用？
在安装目录旁放一个空的 portable.flag 文件，应用数据（对话、设置、模型缓存）就会跟随安装目录存储，整个文件夹拷到 U 盘即可随处使用。
我的对话和 API Key 安全吗？
对话、配置与记忆只写在本机的应用数据目录（每个 Agent 各自独立子目录）与本地存储中，项目不含任何遥测或统计上报。需要注意：API Key 发往你所配置的模型服务端是必要环节，这部分请求会经过你的网络。
